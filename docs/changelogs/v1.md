# Changelog | CryptoSharia API v1

Format mengikuti [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), dan proyek memakai [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-04-19

### Added

- Modul auth (signup, signin, verify, refresh, signout, forgot/reset password, profil user).
- Modul token dengan status syariah (halal, haram, syubhat) dan data quote.
- Modul post, tag, dan user dengan manajemen role/status.
- Contact form message.
- Upload asset dan upload gambar.
- Endpoint ops dan seed untuk internal dev.
- Auth API key dan JWT Bearer.
