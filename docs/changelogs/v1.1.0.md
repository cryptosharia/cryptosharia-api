# Changelog | CryptoSharia API (v1.1.0)

Format mengikuti [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), dan proyek memakai [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added

- Autentikasi passwordless via OTP: `POST /auth/otp/request` (kirim kode 6 digit ke email) dan `POST /auth/otp/verify` (verifikasi, langsung buat sesi; akun dibuat otomatis jika email belum terdaftar). Keduanya dilindungi rate limit (429 + header `Retry-After`).
- Endpoint `POST /auth/signout-all` untuk signout semua sesi aktif.
- Endpoint `GET /health` untuk health check, publik tanpa auth.

### Changed

- Login kini passwordless, sesi didapat dari `otp/request` → `otp/verify`, bukan dari `signin`/`signup` (endpoint lama dihapus, lihat `Removed`).
- `POST /auth/refresh` sekarang hanya mengembalikan `{ accessToken }` (sebelumnya `{ user, accessToken, refreshToken }`).
- Seluruh response tidak lagi dibungkus envelope response: endpoint list items mengembalikan array datar dengan total item di header `total-items` (untuk pagination), objek tunggal dikembalikan langsung.
- Respons error distandarisasi menjadi `{ error, message, details }` (sebelumnya envelope generik), termasuk kode konflik spesifik seperti `SLUG_CONFLICT`, `TICKER_CONFLICT`, `NAME_CONFLICT`, `TAG_IN_USE`, dll.
- Role `tokens_manager` di-rename menjadi `cryptoassets_manager`.
- Modul token di-rename menjadi cryptoasset, semua endpoint pindah path: `/tokens` → `/cryptoassets`, `/tokens/{id}` → `/cryptoassets/{id}`, `/tokens/quotes` → `/cryptoassets?...&quote=true` (data pasar kini ikut dalam response list/detail, bukan endpoint terpisah).
- Respons `GET /auth/me` bertambah field `status`, `lastLoginAt`, `createdAt`, `updatedAt`, `updatedBy`.
- Default `limit` untuk list post, cryptoasset, dan tag naik dari 10 ke 20.
- Operasi delete dan signout sekarang return `204 No Content` (sebelumnya 200 dengan body).
- Deskripsi dan pesan error API diganti ke Bahasa Indonesia.

### Removed

- Endpoint auth lama: `POST /auth/signup`, `POST /auth/signin`, `POST /auth/verify`, `POST /auth/password/forgot`, `POST /auth/password/reset`.
- Seluruh endpoint token: `/tokens`, `/tokens/quotes`, `/tokens/{id}`.
- Query param `notify` pada `POST /messages`.
- Field `permissions` dan `isEmailVerified` dari respons user.
- Endpoint dev internal: `/seed/demo` dan `/ops/assets/cleanup`.
